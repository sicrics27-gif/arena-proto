# 아레나 시험판 (임시 이름)

컴퓨터 상대와 1:1로 한 판 하는 **1단계 시험판**입니다. 이름·그림·소리 모두 임시입니다.

- 파일 하나(`index.html`)로 돌아갑니다. 설치·서버·외부 파일 없음.
- 휴대폰 터치 기준. 키보드(시험용): 이동 WASD/방향키, 공격 J, 방어 K, 회피 L.

## 지금 들어 있는 규칙 (모두 새로 짠 것)

- 원형 경기장에서 체력 100으로 시작, 먼저 0이 되면 패배. 제한 시간 120초(끝나면 체력 많은 쪽 승).
- 공격: 연속 3번째 타격이 크게 들어가고 멀리 밀어냄.
- 방어: 앞쪽 공격을 막고 상대를 잠깐 멈추게 함. 누르는 동안 게이지가 줄고 놓으면 참.
- 회피: 짧게 순간 이동하며 무적. 다시 쓰기까지 1.3초.
- 아이템: 회복 / 힘 / 속도가 바닥에 생김.
- 35초부터 안전 구역이 줄어들고, 밖에 있으면 체력이 깎임.

## 원작과의 선

- 옛 게임에서 가져온 것은 "작은 경기장에서 실시간으로 치고받는 손맛" 한 가지뿐입니다.
- 원작의 이름·캐릭터·그림·음악·효과음·글·지도 배치·수치는 쓰지 않았고, 원작 파일도 받거나 열어 보지 않았습니다.

## 그림·소리 출처

| 종류 | 출처 | 사용 조건 |
|---|---|---|
| 그림(캐릭터·경기장·버튼) | `index.html` 안에서 코드로 직접 그림 | 자체 제작 |
| 효과음 | 브라우저 소리 합성 기능으로 코드에서 직접 생성 | 자체 제작 |
| 글꼴 | 기기 기본 글꼴 | 별도 파일 없음 |

외부에서 가져온 그림·소리·글꼴 파일은 없습니다.
