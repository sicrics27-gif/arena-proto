# 아레나 시험판 (임시 이름) — v0.7

컴퓨터 상대와 1:1로 한 판 하는 **1단계 시험판**입니다. 이름·그림·소리 모두 임시입니다.

- `index.html`과 `assets/` 폴더(그림 4장, 효과음, 배경 음악)로 돌아갑니다. 설치·서버 없음.
- 휴대폰 터치 기준. 키보드(시험용): 이동 WASD/방향키, 공격 J, 방어 K, 회피 L, 한방 I.

## 지금 들어 있는 규칙 (모두 새로 짠 것)

- 둥근 경기장에서 체력 100으로 시작, 먼저 0이 되면 패배. 제한 시간 120초(끝나면 체력 많은 쪽 승).
- 공격: 약한 타격 2, 연속 3번째 타격은 6이고 상대를 멀리 밀어냄.
- 방어: 앞쪽 공격을 막고 상대를 잠깐 멈추게 함. 누르는 동안 게이지가 줄고 놓으면 참.
- 회피: 짧게 순간 이동하며 무적. 다시 쓰기까지 1.3초.
- 한방: 0.45초 모았다가 누른 순간의 상대 방향으로 쏘는 큰 공격(피해 26). 다시 쓰기까지 6초.
- 충격 벽: 경기장 가장자리. 닿으면 1.1초 굳고 피해 6. 한 번 굳은 뒤 2.5초 동안은 다시 안 걸림. 10초부터 45초까지 벽이 좁혀 옴.
- 아이템: 회복 / 힘 / 속도가 바닥에 생김.

### 속성 (v0.5에서 추가)

시작 전에 검·신발·한방 세 칸에 불·물·바람·땅 중 하나씩 고릅니다. 상대(컴퓨터)는 매 판 무작위. 고른 속성은 그 기기에만 기억됩니다.

| | 불 | 물 | 바람 | 땅 |
|---|---|---|---|---|
| 검 | 맞은 상대가 2초 불탐(초당 1.5) | 맞은 상대가 1.2초 느려짐(-35%) | 밀어내는 힘 +40% | 피해 +50%, 밀어내는 힘 -30% |
| 신발 | 회피 직후 0.45초 안에 치면 강타 | 회피 다시 쓰기 1.3 → 0.8초 | 이동 속도 +15% | 밀려나는 거리 -40%, 벽 굳는 시간 -35% |
| 한방 | 피해 24 + 3초 불탐 | 피해 16 + 1.2초 얼어붙음 | 피해 20, 빠른 탄, 4.5초마다, 밀어냄 +50% | 피해 34, 느리고 큰 탄, 6.5초마다 |

- 가져온 것은 "속성 있는 장비를 골라 내 싸움 방식을 만드는 재미"뿐입니다. 네 가지 속성 이름은 여러 게임이 쓰는 흔한 소재이고, 칸 구성(검·신발·한방)과 효과·수치는 새로 정했습니다. 옛 게임의 아이템 이름·그림·수치·강화 단계는 쓰지 않았습니다.
- 강화(+1~+9 같은 성장)는 아직 없습니다. 저장 기능과 함께 다음 단계에서 다룹니다.

## 살린 재미와 원작과의 선

- 가져온 재미는 두 가지뿐입니다.
  1. 작은 경기장에서 실시간으로 치고받는 손맛
  2. 상대를 위험한 가장자리로 몰아 굳힌 뒤 큰 한 방을 꽂아 넣는 재미 (대표님 기억에서 나온 것)
- 그 밖의 규칙·구성·수치는 새로 짰습니다. 사각 링·전깃줄·대포 같은 원래 모습은 쓰지 않고, 둥근 경기장·좁혀 오는 충격 벽·모아 쏘는 한방으로 바꿨습니다.
- 옛 게임들의 이름·캐릭터·그림·음악·효과음·글·지도 배치·수치는 쓰지 않았고, 원작 파일도 받거나 열어 보지 않았습니다. 참고한 것은 공개 기사와 대표님 기억뿐입니다.

## 그림·소리 출처

| 종류 | 출처 | 사용 조건 |
|---|---|---|
| 캐릭터·돌 타일 바닥·얼음 덩어리·나무·바위·아이템·속성별 한방 | `tools/render/`의 3D 모형을 직접 빚어 찍어 낸 그림 | 자체 제작 |
| 충격 벽·번개·빛·불꽃 효과, 표시줄·버튼 | `index.html` 안에서 코드로 그림 | 자체 제작 |
| 효과음 5종·배경 음악 | Ninja Adventure - Asset Pack (Pixel-boy, AAA) https://pixel-boy.itch.io/ninja-adventure-asset-pack | CC0 — 상업 이용 가능, 출처 표기 의무 없음 |
| 글꼴 | 기기 기본 글꼴 | 별도 파일 없음 |

자세한 내용은 `assets/SOURCES.md`에 있습니다. 옛 게임의 그림·소리는 쓰지 않았습니다.

- 그림 방식의 변천: 코드로 그린 그림(v0.3~0.5) → 무료 도트 그림 묶음(v0.6) → 직접 빚어 찍은 3D 그림(v0.7). 대표님이 원한 "입체로 빚어 찍은 옛 게임 느낌"에 맞춘 것이 v0.7입니다.
- 캐릭터는 우리 고유 디자인(털모자 쓴 아이: 나 = 방울 모자, 컴퓨터 = 귀 달린 모자)이고, 이름은 아직 없습니다.
